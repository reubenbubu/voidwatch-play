VOIDWATCH Privacy Policy

Last updated 26 October 2026

VOIDWATCH is a free tower defense game that runs in your web browser at reubenbubu.github.io/voidwatch-play. This page explains what data the game uses. In short: your save stays on your device, and if you turn on cloud save, it is kept in your own Google Drive. The developer never receives it.

What the game stores on your device

The game saves your progress (cleared sectors and best results), skills, CODEX entries, briefings and settings in your browser's local storage. This data stays on your device. The game has no accounts, no analytics, no advertising and no tracking cookies, and it sends none of this data to the developer.

Optional cloud save with Google Drive

Cloud save is off unless you press SIGN IN WITH GOOGLE in Settings. When you sign in:

  • The game asks Google for the drive.appdata permission only. It lets the game read and write its own hidden app folder in your Google Drive. The game cannot see, open or change any of your other Drive files.
  • The game keeps one file, voidwatch-save.json, in that hidden folder. It holds the same save data listed above: progress, bests, skills, CODEX, briefings and settings.
  • The game reads your Google account email address so it can show which account is connected. The email and the save file's ID are stored in your browser's local storage on that device only.
  • The sign-in token from Google is kept in memory only for as long as the page is open, and is never stored or sent anywhere except to Google's own servers.

The game talks directly from your browser to Google. There is no VOIDWATCH server, so the developer has no access to your Google account, your email address or your save file.

How Google data is used

VOIDWATCH uses data from Google APIs only to save and load your game progress in your own Drive. It does not sell, share or transfer this data, use it for advertising, or let anyone read it. VOIDWATCH's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Services the game loads

  • GitHub Pages hosts the game. GitHub may log basic request information such as your IP address; see the GitHub Privacy Statement.
  • Google Fonts supplies the game's fonts, so Google receives a request when the game loads; see the Google Privacy Policy.
  • Google Identity Services and the Google Drive API load only if you sign in to cloud save, under the same Google Privacy Policy.

Removing your data

  • Stop syncing: press SIGN OUT in Settings. This also forgets the link on that device.
  • Remove the game's access: visit myaccount.google.com/permissions and remove VOIDWATCH.
  • Delete the cloud save: in Google Drive, open Settings → Manage apps, find VOIDWATCH and choose Delete hidden app data.
  • Delete the save on a device: use RESET in the game's Settings, or clear the site's data in your browser.

Children

The game does not knowingly collect personal information from anyone. Cloud save is optional and needs a Google account, which follows Google's own age rules.

Changes and contact

If this policy changes, the new version will appear on this page with a new date. Questions or requests: open an issue at github.com/reubenbubu/voidwatch/issues.
